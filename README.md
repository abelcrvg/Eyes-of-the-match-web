# Eyes of the Match Web

Simulador 3D de arbitragem e VAR executado diretamente no navegador.

## Primeiro marco

- Campo 3D
- Jogadores e bola
- Câmera de transmissão
- Movimento básico
- Motor de partida separado da renderização
- Estrutura preparada para replay e VAR

## Princípios

- Simulação procedural e determinística sempre que possível.
- IA opcional: não é necessária para jogar.
- Motor de regras separado da interface e da renderização.
- Prioridade para desempenho no navegador.
